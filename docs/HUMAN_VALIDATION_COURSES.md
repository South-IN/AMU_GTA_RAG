## Review requirement

For each course, reviewers must compare the extracted record with the original PDF and verify:

- Course name, code, category, faculty and campus
- Duration, specialization and intake
- Eligibility, age limit and selection process
- Test details, additional information and page references
- Inherited values from merged table cells

Only approved records may enter the retrieval index.
